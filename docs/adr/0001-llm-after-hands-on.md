# สอนใช้ก่อน เข้าใจทีหลัง — บท LLM เป็น B4 ต่อจาก Git

แผนหลักสูตรมีทางเลือกจะสอน "LLM คืออะไร" ก่อนให้ผู้เรียนแตะ Claude Code (แทรกเป็น B1) หรือสอนหลังจากผู้เรียนใช้งานจริงมาแล้ว เราเลือกอย่างหลัง: บท LLM เป็น **B4** ต่อจาก B3 Git เพราะตรงหลักการคอร์สข้อ 1 ("ได้ผลลัพธ์ที่เห็นจริงภายใน 30 นาทีแรก") — ผู้เรียนที่ติดตั้ง Claude Code, อ่าน diff และ commit มาแล้ว 2–3 บท จะมีประสบการณ์จริงให้บททฤษฎีชี้กลับมาอธิบาย (สอนแบบเกลียว ตามหลักการข้อ 6) ทำให้ hallucination, context window และความไม่แน่นอน ผูกกับนิสัยที่เขาฝึกมาแล้ว ไม่ใช่ความรู้ลอย ๆ

## Considered Options

- **แทรกเป็น B1 ก่อนใช้ Claude Code** — ถูกตามลำดับตรรกะ แต่ผู้เรียนไร้พื้นฐานจะได้แต่คำศัพท์โดยไม่มีประสบการณ์ให้ผูก และดันผลลัพธ์แรกออกไป; ต้องเลขบทใหม่ทั้งภาค B
- **ใช้ก่อน เข้าใจทีหลัง (B4) — เลือกไว้** — ต้นทุนคือผู้เรียนใช้เครื่องมือ 2–3 บทโดยไม่รู้กลไกข้างใน ซึ่งยอมรับได้เพราะบท B1–B3 สอน "สั่งและตรวจ" อยู่แล้ว ไม่พึ่งความเข้าใจกลไก
